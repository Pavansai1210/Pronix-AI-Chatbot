
# Pronix AI Chatbot — Project Overview

## 1. Introduction

Pronix is an AI-powered virtual assistant built using the Kore.ai XO Platform and deployed through Telegram.

## 2. Project Objective

The objective is to create a conversational assistant that supports account management and answers user questions through an interactive chatbot.

## 3. Main Modules

### Welcome Module
- Greets users.
- Displays Login and Register options.

### User Registration
- Collects user registration details.
- Connects with MockAPI.

### User Login
- Collects login information.
- Uses the account workflow and API integration.

### Account Management
- Modify Account
- Delete Account

### Question and Answer Module
- Processes user questions.
- Provides relevant FAQ or AI-generated responses.
- Uses fallback handling when an answer is unavailable.

## 4. Platform and Tools

- Kore.ai XO Platform
- Dialog Tasks
- Intents and Entities
- JavaScript
- REST API
- MockAPI
- Telegram
